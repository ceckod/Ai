# Качване на нова версия на сайта

Тук качваш **само един .zip файл** (например `helfi.zip`) — с бутона
"Add file → Upload files" в GitHub, директно от тази папка (`_upload/`).

След commit-ването, GitHub автоматично:
1. разархивира zip-а,
2. разпределя файловете по правилните места в проекта (замества старите),
3. изтрива zip-а оттук,
4. пуска нов commit — което автоматично рестартира и публикуването
   в GitHub Pages (сайтът се обновява сам след 1-2 минути).

Не се налага да разархивираш нищо сам и да качваш файлове един по един.

**Важно:** качвай само по един zip в даден момент и изчакай action-ът
("Unpack Upload" в раздел Actions) да завърши (зелена отметка), преди
да качиш следващ.
