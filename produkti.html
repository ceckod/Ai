🔓 Вход с GitHub

Влизаш веднъж с "ключ" (token) за своя repo. След вход виждаш пълните форми за редакция — всяка промяна прави commit директно в GitHub, автоматично. Без вход страницата е само за преглед.

Как да си направя такъв ключ (1 минута)
  1. Отвори github.com/settings/tokens?type=beta
  2. Натисни "Generate new token" (fine-grained)
  3. Дай име, избери Repository access → Only select repositories → избери своя repo
  4. Под Permissions → Repository permissions намери Contents и избери Read and write
  5. Генерирай и копирай ключа (показва се само веднъж) — постави го в полето по-горе
